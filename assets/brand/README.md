# PVE Companion brand assets

The PVE Companion mark is an original asset created for this project. Three
compact server nodes connect around a central status beacon to communicate the
app's datacenter-observability focus at small icon sizes. It intentionally
does not reproduce the Proxmox wordmark or orange X symbol.

- `pve_companion_app_icon_master.png` is the retained 1254 × 1254 source image.
- `pve_companion_mark.png` is the 256 × 256 in-app mark.
- Platform app-icon renditions are generated from the master under the iOS and
  macOS asset catalogs.

The image was generated with OpenAI's built-in ImageGen using this final
prompt:

> Create a polished square app icon for an Apple-first, open-source Proxmox
> compatible datacenter companion app. Show three compact server nodes linked
> around one central status beacon. Use simple vector-like geometry that stays
> legible at 16 px, with midnight navy, cyan/teal, and a small mint status
> accent. Opaque full-bleed background, no text, no letters, no trademarked
> Proxmox orange X, no device frame, and no transparent pixels.

The generated asset is included under the repository's Apache-2.0 license.
Do not replace it with third-party logo artwork unless the source and license
are documented here.
